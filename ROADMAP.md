# ACE roadmap

- **0.1** — adaptive block-analysis/planner foundation, RAW/RLE/DELTA/LZ/Huffman, Format 1.0.
- **0.2** — deterministic cost model, scalar rANS, Format 1.1 block index/random access, bounded parallel blocks, dictionary abstractions, standardized JSON benchmarks.
- **0.3** — SIMD, interleaved rANS, richer transform pipelines, improved LZ, memory pools, streaming/backpressure and long-distance fingerprints.
- **0.4** — content-defined chunking, dictionary training and online planner statistics.
- **0.5** — stable C ABI/FFM integration and AdaptiveDB semantic hints.
- **0.6** — GraphNet-specific graph/reference transforms and compression-policy integration.
- **0.7+** — self-tuning cost calibration, replica-aware delta transfer and hot/warm/cold recompression policies.
